# LogiPro — site vitrine

Site public de présentation de **LogiPro**, plateforme intégrée de gestion :
Comptabilité, Gestion Carburant, Shipping, TeamPro, Logistique, PeoplePro et Gestion de Yard.

- Site statique : `index.html` + `assets/` (aucune installation, aucun build).
- Hébergement : Vercel (`vercel.json` : en-têtes de sécurité et cache des images).
- Formulaire « Demander une démo » : ouvre la messagerie vers l'adresse `CONTACT_EMAIL` définie en bas de `index.html`.

Aperçu local :

```bash
python -m http.server 8080
```
